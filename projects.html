Completed

Grade Analytics & Reporting Tool

Capstone Project — Lead Developer

Problem Statement

Class advisers were consolidating prelim, midterm, and final scores by hand across spreadsheets, which was slow and error-prone and made it hard to catch struggling students early enough to help them.

Technologies & Tools

Python Django MySQL Bootstrap Chart.js

Key Contributions

  • Designed the relational database schema for students, subjects, and grade components
  • Built the backend grade-computation logic with configurable weights per term
  • Developed an adviser dashboard with sortable tables and per-subject performance charts
  • Wrote unit tests for the grade-computation module

Outcome & Impact

Piloted with three sample class sections during the capstone defense. Manual grade consolidation time dropped significantly, and the dashboard automatically flagged at-risk students so advisers could follow up earlier.

Sample output — grade report dashboard (mock data for demonstration)

Course Project — Backend Developer (Java, OOP)

Problem Statement

Practiced object-oriented design and data handling by replacing spreadsheet-based student record-keeping with a small desktop application for adding, editing, and deactivating student records.

Technologies & Tools

Java Swing MySQL JDBC

Key Contributions
