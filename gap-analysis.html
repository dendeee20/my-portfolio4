Gap Analysis

Closing the Distance to My Goals

A honest comparison between the skills I have today and what my career goals actually require, with a concrete plan — not just a wish list — for closing each gap.

My current skills are strongest in core programming, databases, and version control. My career goals, though, call for cloud deployment, secure coding, modern frontend frameworks, DevOps practices, and applied data analytics — areas I've only touched on so far. The five gaps below are the ones I'm prioritizing first, along with how I plan to close each one.

Current vs. Required

Five Priority Skill Gaps

Where I stand now, where I need to be, and how I'll get there.

Cloud Computing (AWS / Azure)

Current: Beginner → Target: Intermediate

"I've only had intro-level exposure to cloud platforms — no deployed project yet."

Plan to Close the Gap
  • Enroll in the AWS Cloud Practitioner certification track
  • Deploy the Grade Analytics Tool on a free-tier AWS/Azure instance
  • Complete guided labs on core services (EC2/App Service, S3)

Cybersecurity Fundamentals

Current: Beginner → Target: Intermediate

"I know common vulnerabilities exist, but I haven't practiced finding or fixing them."

Plan to Close the Gap
  • Take an introductory penetration-testing course (e.g., TryHackMe path)
  • Practice in lab simulations such as OWASP Juice Shop
  • Apply a secure-coding checklist to my existing personal projects

Modern Frontend Frameworks (React)

Current: Beginner → Target: Intermediate

"Comfortable with vanilla JavaScript, but I haven't built with a component-based framework."

Plan to Close the Gap
  • Complete a structured React fundamentals course
  • Rebuild this portfolio's skill-filter feature as a React component, for practice
  • Contribute the frontend for a small group or class project using React

DevOps & CI/CD Pipelines

Current: Novice → Target: Intermediate

"I only deploy manually right now — I've never set up an automated pipeline."

Plan to Close the Gap
  • Learn GitHub Actions and set up a simple CI pipeline for a personal repo
  • Get hands-on with Docker by containerizing a small app
  • Automate deployment of the Grade Analytics Tool as a practice pipeline

Data Analytics & Applied Machine Learning

Current: Beginner → Target: Intermediate

"I can clean and explore data with Pandas, but I haven't applied any machine learning models yet."

Plan to Close the Gap
  • Study scikit-learn fundamentals — classification and regression basics
  • Extend the Grade Analytics Tool with a simple "at-risk student" prediction feature
  • Practice on public datasets through guided notebooks and tutorials
Roadmap

How I'll Close These Gaps Over Time

A phased plan so this stays a real commitment, not just a list.

Now

Start the AWS Cloud Practitioner prep and a cybersecurity fundamentals course; begin React basics alongside current coursework.

Next 6–12 mo.

Deploy a personal project on a cloud free tier, containerize it with Docker, and set up a basic CI/CD pipeline with GitHub Actions.

1–2 Years

Apply React on a real group or freelance project, and extend the Grade Analytics Tool with a basic machine-learning feature.

Ongoing

Revisit this page every term and move each skill from "current" to "target" as evidence, not just intention.
