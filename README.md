# Dennis Velez Portfolio

GitHub Pages-ready static portfolio.

## Files
- `index.html` — Home
- `skills.html` — Skills
- `projects.html` — Projects
- `career-goals.html` — Career Goals
- `gap-analysis.html` — Gap Analysis
- `css/style.css` — all colors, typography, spacing, layout, responsive design
- `js/script.js` — theme toggle, mobile navigation, animations, skill filtering
- `.nojekyll` — keeps GitHub Pages serving the site as a static website

## GitHub Pages
Upload the **contents of this folder** to the repository root (not the ZIP file itself).
Then go to **Settings → Pages → Deploy from a branch → main → / (root)**.
